## 📌 Visão Geral

O **Cognita Hub** é uma plataforma educacional desenvolvida como projeto prático na disciplina de **Gestão de Projetos** do curso de **Gestão da Informação** na **Universidade Federal do Paraná (UFPR)**.

O projeto uniu metodologias clássicas e ágeis de gerenciamento de projetos (escopo, cronograma, riscos, sprints) à engenharia de software contemporânea, resultando em um produto digital moderno voltado à autoavaliação e retenção de conhecimento por meio de questionários gamificados e trilhas de estudo estruturadas.

---

## ✨ Funcionalidades

- **🎯 Quizzes Gamificados:** Desafios temáticos por áreas de estudo, com cálculo dinâmico de pontuação e estatísticas.
- **📚 Biblioteca de Fontes Curadas:** Seleção de livros, artigos, podcasts e links essenciais para aprofundamento.
- **⚡ Arquitetura Reativa Moderna:** Construído com **Nuxt 3** e componentes modulares em **Vue 3**.
- **🎨 Design Acessível e Imersivo:** Layout fluido com microinterações, transições suaves e adaptabilidade para telas mobile.

---

## 🛠️ Tecnologias Utilizadas

- **Framework Web:** [Nuxt 3](https://nuxt.com/) (SSR / SSG)
- **Biblioteca UI:** [Vue.js 3](https://vuejs.org/) com Composition API
- **Estilização:** CSS Moderno e Tailwind/Utility classes
- **Gerenciamento de Pacotes:** `npm` / `pnpm`

## 🚀 Como Executar Localmente

### Pré-requisitos
Node.js versão 18 ou superior instalado.

```bash
git clone https://github.com/brunomarafiga/cognahub.git
cd cognahub
npm install
```

### Modo de Desenvolvimento
```bash
npm run dev
```
Abra o navegador em `http://localhost:3000`.

### Build de Produção
```bash
npm run build
```
